本地內容管理・快速教學

不用寫 HTML，也能整理作品與文章

以下格式適用於「新增作品」的作品說明、「新增文章」的正文，以及「編輯文字」中既有作品／文章的內文。其他欄位（姓名、摘要、聯絡資料等）是純文字，不使用這套格式。

一、修改已經發布的內容

  1. 在專案資料夾開啟命令列，執行 python tools/content_manager.py。
  2. 切到「編輯文字」，打開「要修改的頁面」，選擇「作品：…」或「文章：…」。剛新增的內容也會出現在下拉清單中。
  3. 修改標題、作品資訊或內文。正文是一個完整文字框，可直接加段落、刪除整段，或剪下後貼到別的位置。
  4. 按內文下方的「大標」「小標」「引言」「引用框」「背景框」「條列」按鈕，就能在游標處插入可改寫的範例。「粗體」可先選中文字再按。
  5. 按「儲存並更新網站」，確認後等待圖片最佳化與 HTML 建置完成，再開啟本機預覽，重新整理檢查。
  6. 本機修改不會自動上線。確認後再用原本的 Git 提交、推送流程，等 GitHub Actions 部署完成。

作品與文章的網址、主圖、圖庫不會因為修改正文而改動。更換主圖請到「頁面圖片」。儲存前的原始 JSON 會備份在 .codex-work/content-backups/日期時間/；如果需要還原，先關閉管理介面，再將該備份複製回原本的 content/works/ 或 content/articles/，最後重新建置。

二、最基本的寫法

符號請用英文半形；標題等符號後要有一個空格。空一行代表新段落，同一段內按 Enter 只換行。每一個標題也建議前後空一行。

想呈現的樣子輸入方式
一般段落直接輸入文字；段落間空一行。
段落大標## 創作的起點
段落小標### 光線與色彩
較大的引言! 從日常的風景開始。
引用／重點框> 讓光線在畫面中慢慢浮現。
粗體這裡是 **重要的文字**。
條列項目每項一行，使用 - 第一項、- 第二項。
有底色的背景框獨立一行 ::: box 開始，寫完後以獨立一行 ::: 結束。

這些是內文的大小層級，不是整個頁面最上方的大標題。頁面標題請改「文章標題」或「作品中文名」；文章的「標題顯示換行」可另行指定斷行。標題與正文的實際尺寸、顏色由共用樣式控制，手機會自動排版。

四、常見問題

  • 背景框無法儲存？ 請確認有結尾的 :::，前後不要加空格。格式錯誤時不會寫入檔案。
  • 引用框要多行？ 每行開頭都加 > ；引言、大標與小標也採相同規則。
  • 只想顯示符號？ 如果一行本來就以 ## 或其他格式符號開頭，在行首加 \，例如 \## 這不是標題。
  • 可以自己指定紅字、字級或放 HTML 嗎？ 目前刻意保留基本樣式，不支援任意 HTML、嵌套框、表格、連結語法或自訂顏色。請用大標、小標、粗體和背景框即可；HTML 會顯示為普通文字。
  • 修改其他欄位會弄亂舊內文嗎？ 沒有修改的正文會保留原資料，不會重新分段。舊文章的引言及引用框也會自動轉成可編輯的寫法。
  • 作品不需要內文？ 可清空作品內文欄；網站仍保留作品圖片與資料。作品預覽維持統一大小、圖片不裁切。
